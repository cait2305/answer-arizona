Spectrum Operator Standard Operating Procedure

Deliver Undelivered Messages to a Client

Verbally relay undelivered messages to a client and move them to the Delivered stack.

SOP IDSOP-42
Manual SectionDELIVERING MESSAGES
SourceRevised Spectrum Manual — July 2023

Purpose

Verbally relay undelivered messages to a client and move them to the Delivered stack.

When all are delivered, the manual says the screen will show “No Undelivered” and “All Delivered.”

Visual Workflow

Display client account
→
Check Undelivered
→
Open Delivering Msg
→
Enter recipient
→
Record recipient
→

→
Repeat

Procedure

1

Display client account

Open the client's account.

2

Check Undelivered

Look for pending messages and advise the client that messages are waiting.

3

Open Delivering Msg

Press IF/DELIVER MSG.

IF / DELIVER MSG
4

Enter recipient

Type the client's name in the Deliver To Field.

5

Record recipient

Press SELECT.

SELECT
6

Open first message

Press SELECT again and relay the message beginning with date/time.

SELECT
7

Mark delivered

Press FILE and move to the next message.

FILE
8

Repeat

Arrow to each remaining message and repeat until all are delivered.

Operator Check

  • Complete step 1 correctly: Display client account.
  • Complete step 2 correctly: Check Undelivered.
  • Complete step 3 correctly: Open Delivering Msg.
  • Complete step 4 correctly: Enter recipient.
  • Complete step 5 correctly: Record recipient.
  • Complete step 6 correctly: Open first message.
  • Complete step 7 correctly: Mark delivered.
  • Complete step 8 correctly: Repeat.
