Spectrum Operator Standard Operating Procedure

Create a Standard Message Ticket

Open, complete, and file a standard Spectrum message ticket.

SOP IDSOP-33
Manual SectionTYPES OF MESSAGES — Message Tickets with NO Labeling
SourceRevised Spectrum Manual — July 2023

Purpose

Open, complete, and file a standard Spectrum message ticket.

Visual Workflow

Open ticket
→
Read instructions
→
Enter caller information
→
Complete routing fields
→
Review
→
File

Procedure

1

Open ticket

Press IF/ENTER MSG.

IF / ENTER MSG
2

Read instructions

Use the account Information Screens; use Page Up/Page Down if needed.

3

Enter caller information

Collect information in the order requested by the account.

4

Complete routing fields

Mark ER Y/N and enter Ofc or O/C in FOR when applicable.

5

Review

Verify names, numbers, spelling, and message content.

6

File

Press FILE.

FILE

Operator Check

  • Complete step 1 correctly: Open ticket.
  • Complete step 2 correctly: Read instructions.
  • Complete step 3 correctly: Enter caller information.
  • Complete step 4 correctly: Complete routing fields.
  • Complete step 5 correctly: Review.
  • Complete step 6 correctly: File.
