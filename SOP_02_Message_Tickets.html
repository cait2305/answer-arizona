Spectrum Operator Standard Operating Procedure

Creating & Documenting Message Tickets

A visual SOP for opening, completing, reviewing, documenting, editing, and filing Spectrum message tickets.

SOP IDSOP-02
SourceRevised Spectrum Manual — July 2023
Manual AreaTypes of Messages / Message Ticket Documentation

Purpose

Use this procedure to create, complete, document, review, and file Spectrum message tickets accurately. This SOP also distinguishes ordinary message tickets, Announce Patch tickets, and Patch calls.

Accuracy is mandatory. The manual states that confirmation of numbers, addresses, and names is mandatory because unclear or incorrect messages can delay assistance.

Procedure A — Create a Standard Message Ticket

1

Check account instructions first

Read the Information screens and follow the order requested by the account. Use Page Up or Page Down to review additional information pages.

2

Open the message ticket

Press IF/ENTER MSG.

IF / ENTER MSG
3

Collect and enter the caller's information

Follow the exact field order requested by the account. For two-page tickets, press TAB to move to the next page.

TAB
4

Mark routing information

Where applicable, mark the ER field Y or N and enter Ofc or O/C in the FOR field so the dispatcher knows whether to hold or pass the message.

5

Review before filing

Verify names, phone numbers, addresses, spelling, and the reason for the call. Write clearly and include who, what, when, and where.

6

File the ticket

Press FILE when the ticket is complete.

FILE

Writing Standard

RequirementManual guidance
VoiceWrite in first person as if the caller is writing the message: I, we, me, mine, my, our.
ClarityUse accurate grammar, correct spelling, and wording that is easy for the dispatcher/on-call/nurse to understand.
CompletenessInclude relevant who, what, when, and where details.
VerificationConfirm names, telephone numbers, and addresses.

Procedure C — Patch Calls

Patch calls do not require a completed message ticket. The manual instructs the operator to simply patch the caller to the client.

Editing, Second Calls, and Cancellations

Manual note: the Copy/Save section is marked “SECTION BEING UPDATED.” Follow current supervisor/dispatcher direction if local practice differs.
  • Use SAVE to edit an undelivered message or place a message on the Incomplete stack.
  • Press FILE after edits are complete.
  • For a second or third call or a cancellation, the manual instructs creating a new ticket and adding side documentation such as *2ND, *3RD, or CANCEL.
  • On a second call, always reconfirm the caller's phone number.
  • Do not allow STAT/STEMI/ASAP-type calls to sit in the Incomplete stack; finish the ticket and alert the dispatcher.

Operator Check

  • I read the account instructions before entering the ticket.
  • I verified all names and numbers with the caller.
  • I used the correct ER and FOR routing fields where required.
  • I documented exceptions/patch results with side documentation.
  • I reviewed the ticket before pressing FILE.
